## Что изучено

- **Цикл `for`** — используется, когда заранее известно количество повторений. Три части в скобках: инициализация счётчика, условие продолжения, шаг. Удобен для перебора диапазона и накопления сумм.
- **Цикл `while`** — используется, когда число повторений заранее неизвестно. Условие проверяется *до* тела цикла, поэтому тело может не выполниться ни разу. Важно менять переменную внутри цикла, иначе он станет бесконечным.
- **Цикл `do while`** — отличается от `while` тем, что условие проверяется *после* тела, поэтому тело гарантированно выполнится **хотя бы один раз**. После `while (...)` обязательна точка с запятой.

Дополнительно освоила `break` (досрочный выход из цикла) и `continue` (пропуск текущего шага).
